# Проверка референсов, 6 октября 2026

Район Балка, Тирасполь. Просмотрен слой изображений Google Maps около 46.8358, 29.6658. В проверенной области видны отдельные фотосферы; сплошного уличного маршрута около Тернополя не обнаружено.

Просмотрено:
- «Зоолюкс», фотосфера Михаила Андреева, февраль 2018: интерьер магазина, через окно виден только фрагмент жилого фасада. По этому снимку нельзя точно назначить внешнему дому адрес; модель отдельного дома по нему не строилась.
- ТЦ «Тернополь», Краснодонская, 41, фотография фасада с пометкой ноябрь 2024: белая отделка, синие горизонтальные полосы, красная узкая полоса, большие витрины нижнего этажа, окна второго этажа, синяя вывеска сверху. Эти признаки перенесены в упрощённую модель. Пропорции, все стороны здания и внутренний план полностью не восстановлены.

Это не полный обход каждого здания. Фасады остальных домов процедурные; этажность берётся из OSM, а при отсутствии данных оценена. Адреса не назначаются по ближайшей улице: отображаются только записанные в OSM street/housenumber. CSV содержит все 409 зданий и статус сопоставления. Для 3D-реконструкции конкретного дома нужны фото с известным адресом и разных сторон; их можно связать через OSM ID в каталоге.
