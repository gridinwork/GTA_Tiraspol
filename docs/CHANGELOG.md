# v0.2.0

- Миникарта по курсу, компас, адресный слой, масштабирование и перемещение большой карты.
- 60 км/ч как физическое ограничение; разгон медленнее.
- Твёрдые стволы 640 деревьев; столбы гнутся и падают при столкновении.
- Детализация машины, салона, колёс и персонажа с суставной анимацией.
- Объёмные элементы фасадов; условная реконструкция Тернополя по просмотренному фото.
- Каталог всех 409 зданий, 279 известных номеров домов. Полная реконструкция всех зданий по фото ещё не выполнена.
- Статические части машины объединены по материалам для уменьшения количества вызовов отрисовки.

Проверка: 36/36 сценариев пройдены как в редакторе, так и в экспортированной Linux-сборке Godot 4.4.1. Windows-сборка экспортирована; нативный запуск на Windows и FPS на UHD 620 в этой среде не проверялись. Предыдущую Windows-версию 0.1 пользователь успешно протестировал.
